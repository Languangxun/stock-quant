# 量化交易相关知识

## BOLL策略
### BOLL（布林带）标准公式

1. **中轨 MB（Middle Band）**
\(MB = SMA(C, N) = \frac{1}{N}\sum_{i=1}^{N}C_i\)

> N 周期收盘价简单均线，标准 N=20

2. **标准差 σ（总体标准差，TA-Lib、通达信默认）**
\(\sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(C_i - MB)^2}\)

3. **上轨 UB（Upper Band）**
\(UB = MB + k \times \sigma\)

4. **下轨 LB（Lower Band）**
\(LB = MB - k \times \sigma\)

> 
> 默认 k=2

#### 衍生指标

- **BBW 布林带宽 BandWidth**（百分比）
\(BBW = \frac{UB - LB}{MB}\)

- **% B 位置指标**（价格在通道内相对位置）
\(\%B = \frac{C - LB}{UB - LB}\)

>% B=1：价格在上轨；% B=0：价格在下轨；>1 突破上轨；<0 跌破下轨

### BOLL 布林带策略核心特点

布林带本质是**基于波动率的通道类指标**，用 20 周期均线 + 2 倍标准差构建动态通道，通道宽度随波动率自动伸缩。

#### ✅ 优点

1. **自带波动率自适应**
震荡期带宽收窄；行情启动、波动放大，带宽自动张开（BBW 变大）。天生适配波动率变化，这也是 BBW 做突破前置信号的基础。
2. **同时提供方向 + 超买超卖参考**
   - 价格在中轨之上：偏多头环境；中轨之下：偏空头环境
   - % B 可以直接定位价格在通道中的位置，方便写量化条件
3. **震荡市天然好用**
经典高抛低吸思路：下轨附近买、上轨附近卖，在长期横盘、区间震荡个股里，胜率往往不错。
4. **规则简单，参数少（默认 N=20,k=2），容易回测、不容易过度拟合**

#### ❌ 短板

1. **趋势大行情里容易反复假信号、来回打脸**
单边持续上涨：价格一直贴着上轨运行，不断触发 “超买卖出”，结果踏空主升浪；
单边持续下跌：价格一直压在下轨，不断抄底被套。
> 
> 一句话：**布林高抛低吸是震荡思路，天生和强趋势矛盾**。
2. **滞后性**
底层是均线 + 标准差，属于滞后指标；暴涨暴跌时轨道来不及跟上。
3. **窄幅盘整后的假突破很多**
BBW 极度压缩后，看起来要选择方向，但是经常是假突破，突破上轨马上回落，突破下轨马上拉回。
4. **对个股基本面突发利空 / 利好无效**
一字板、突发公告跳空，K 线直接跳出轨道，指标没有预警能力。

### BOLL 策略适用范围
#### ✅ 适合场景

1. **震荡行情（最适合）**
指数、个股长期箱体震荡，没有明确单边趋势。
配套策略：下轨附近做多，上轨止盈，中轨作为强弱分水岭。
2. **波动率收敛后做突破策略**
思路反过来：BBW 长期压缩（低波动）→带宽突然放大，等待突破，做趋势启动。

> 这个用法，**不是抄底摸顶，是抓波动率爆发**，适合做量化过滤。

3. **作为辅助过滤指标，而不是单一主指标**
   - 用 ADL(腾落指数)/ADR(涨跌比率) 判断大盘广度环境
   - 用 ADX（平均趋向指数）判断当前是不是趋势行情（ADX 低 = 震荡，允许 BOLL 高抛低吸；ADX 高 = 强趋势，放弃 BOLL 反转信号）
   - BOLL、% B、BBW 做入场 / 出场过滤

#### ❌ 不适合场景

1. **持续单边趋势行情（强主升、连续下跌）**
连续主升阶段，单纯用布林上轨卖出会持续踏空。
2. **流动性很差、经常跳空的小票**
跳空缺口会直接击穿轨道，信号失真。
3. **长期走下降通道、阴跌不止的标的**
不断碰下轨，每次下轨买入都是接飞刀。

### 两种主流 BOLL 策略范式

1. **震荡反转型（高抛低吸）**
价格触下轨 + ADX 偏低（<20，确认震荡）买入；碰到上轨卖出。
风险：一旦走出趋势，连续亏损。
2. **波动率突破型（顺势）**
BBW 处于近期低位收敛 + 收盘价站稳上轨 + 价格在中轨上方，顺势做多。
风险：假突破多，需要大盘广度、趋势指标二次过滤。

### 量化策略的搭配建议
- 过滤入场：虽然满足动量买入条件，但 % B 过高（已经靠近上轨），暂缓买入，避免追高在短期压力位；
- 辅助风控：价格持续贴下轨、BBW 快速放大，提示波动率风险，配合止损。

## MACD指标
### 一、计算公式

EMA 平滑系数：\(\alpha=\dfrac{2}{N+1}\)

\(EMA_N = EMA_{prev} \times (1-\alpha) + Close \times \alpha\)

1. **DIF（快线，DIFF）**

\(DIF = EMA(C,12) - EMA(C,26)\)

> 
> 12 周期快速 EMA − 26 周期慢速 EMA，代表长短均线差值、动量方向

2. **DEA（慢线、信号线，Signal）**

\(DEA = EMA(DIF,9)\)

> 
> 对 DIF 做 9 日指数平滑，过滤噪音

3. **MACD 柱（BAR，红绿柱）**

\(BAR = 2\times (DIF - DEA)\)
### 二、核心研判要素

#### 1. 0 轴（多空分水岭）

- **DIF、DEA 在 0 轴上方**：12EMA＞26EMA，中期多头趋势环境，金叉质量更高
- **DIF、DEA 在 0 轴下方**：12EMA＜26EMA，中期空头环境，金叉大多只是反弹，容易失败
- 穿越 0 轴：代表长短均线趋势反转，属于级别更大的信号，比普通金叉死叉级别更高

### 2. 金叉、死叉

- **金叉：DIF 自下向上穿过 DEA → BAR 由负转正（红柱）**
  - 0 轴上方金叉：多头趋势内的加仓信号，优先采信
  - 0 轴下方金叉：下跌途中反弹信号，偏左侧，风险高，适合轻仓试错
- **死叉：DIF 自上向下跌破 DEA → BAR 由正转负（绿柱）**
  - 0 轴上方死叉：多头趋势转弱，减仓 / 止盈信号
  - 0 轴下方死叉：空头延续，继续规避

> 
> 震荡区间会连续反复金叉死叉，来回打脸、损耗手续费，**所以 MACD 金叉死叉不能单独当主策略**，需要 ADX 过滤震荡。

#### 3. 红绿柱（动能强弱，比交叉更早预警）

- 红柱：DIF＞DEA，多头动能；**红柱持续拉长 → 多头力量增强；红柱逐步缩短 → 上涨动能衰减，哪怕还没出现死叉，也可以提前减仓**
- 绿柱：DIF＜DEA，空头动能；绿柱放大，空头发力；绿柱持续收窄，做空动能衰竭，反弹临近
- 柱体拐点，是 MACD 最早的信号，比交叉提前

#### 4. 顶背离 & 底背离（MACD 最有价值的用法，用来识别动能衰竭）

- **顶背离**：股价创出阶段新高，但是 DIF（或红柱峰值）没有同步新高，一波比一波低
含义：价格创新高，但是上攻动能跟不上，多头衰竭，**见顶预警信号**；背离≠马上跌，需要等后续死叉 / 跌破均线确认，不要提前猜顶
- **底背离**：股价创出阶段新低，但是 DIF 低点（绿柱低点）抬升，不再创新低
含义：价格继续创新低，抛压动能衰竭，下跌接近尾声；背离只是预警，需要金叉确认，不要重仓左侧抄底

> 
> 背离可以连续多次出现（二次、三次背离），多次背离后反转概率更高。

### 三、MACD 特点、适用场景

✅ 优点

1. 同时融合**趋势（EMA）+ 动量（差值）**，一个指标兼顾趋势方向与动能
2. 信号层级丰富：0 轴位置、交叉、柱体、背离，可以多层过滤
3. 可用于日线、周线；周线 MACD 级别更大，适合你之前的周 K 动量体系
4. 和 DMI、BOLL、ADX 天然互补：ADX>25 趋势行情，MACD 交叉 / 背离可靠性提升；ADX<20 震荡行情，MACD 噪音巨大

❌ 缺点

1. **滞后指标**，底层是 EMA 平滑，暴涨暴跌行情信号滞后
2. 震荡市假信号爆炸，连续金叉死叉来回止损，纯 MACD 金叉策略回测通常收益差、胜率低
3. 没有固定超买超卖边界，不同价格标的 MACD 数值不能横向对比（PPO 百分比 MACD 可以解决这个问题）
4. 一字板、突发消息跳空，均线被强行拉开，指标失真

✅ 适合场景

- 趋势行情（ADX＞25）：顺势用 0 轴上方金叉做多、顶背离 + 死叉止盈
- 趋势末期：用背离识别动能衰竭、逃顶

❌ 不适合场景
- 长期窄幅震荡标的（ADX＜20）：尽量放弃 MACD 交叉信号，改用 BOLL 震荡策略



## DMI动量指标
DMI 是一套**趋势识别体系**，不是单一指标，整套包含 4 个分量：**+DI、-DI、DX、ADX**。

> 
> 核心定位：区分【趋势行情 / 震荡行情】，同时给出趋势方向 + 趋势强度。
> 适用：个股、指数；非常适合和 BOLL、动量策略搭配做行情模式切换。

> 
> 默认参数：周期 N=14

### 一、DM 趋向变动值（+DM、-DM）

定义：
- H：当日最高价
- L：当日最低价
- PH：前一日最高价
- PL：前一日最低价

1. **+DM（上升趋向值）**

\(+DM = H - PH\)
只有满足：\(H-PH > PL-L\)，并且 \(H>PH\)，才取这个值；否则 +DM = 0

2. **-DM（下降趋向值）**

\(-DM = PL - L\)
只有满足：\(PL-L > H-PH\)，并且 \(L<PL\)，才取这个值；否则 -DM = 0

> 
> 当天向上突破前高，产生 + DM；向下跌破前低，产生 - DM；两者不会同时有效；高低点没有向外扩张，DM=0。

然后对 +DM、-DM 做 **Wilder 平滑（不是普通 MA！）**

\(\text{+DM14} = \text{前+DM14} - \frac{\text{前+DM14}}{14} + \text{本期+DM}\)

\(\text{-DM14} = \text{前-DM14} - \frac{\text{前-DM14}}{14} + \text{本期-DM}\)

3. **TR 真实波幅（True Range）**

\(TR = \max(H-L,\ |H-PC|,\ |L-PC|)\)
PC = 前收盘价，同样做 Wilder 平滑得到 TR14

### 二、+DI、-DI 方向线（最核心的多空方向）

\(+DI_{14} = \frac{+DM14}{TR14} \times 100\)

\(-DI_{14} = \frac{-DM14}{TR14} \times 100\)

✅ 解读：

- \(\boldsymbol{+DI > -DI}\)：多头趋向占优，向上力量更强
- \(\boldsymbol{-DI > +DI}\)：空头趋向占优，向下力量更强
- +DI、-DI 数值都很低、缠绕在一起：多空没有方向，震荡

> 
> 交叉信号：
> +DI 上穿 -DI → 趋向转多信号
> -DI 上穿 +DI → 趋向转空信号
> ⚠️ 震荡市里面交叉会频繁反复，假信号极多！**必须搭配 ADX 过滤**

### 三、DX 趋向指数

\(DX = \frac{|+DI - (-DI)|}{+DI + (-DI)} \times 100\)
DX 范围 0～100
DX 越大，+DI 和 - DI 差距越大，方向越明确。

### 四、ADX 平均趋向指数（你前面重点用的）

ADX = DX 的 Wilder14 期平滑

\(ADX_{14} = \text{前ADX} - \frac{\text{前ADX}}{14} + \text{本期DX}\)

✅ ADX 只代表**趋势强度，不分涨跌方向**

- ADX > 25：趋势行情，适合趋势策略、BOLL 突破、动量策略
- ADX < 20：震荡行情，适合 BOLL 高抛低吸反转策略
- 20～25：模糊区，尽量降低仓位或者不做 DMI 信号
- ADX 低位慢慢抬升：趋势正在酝酿加强
- ADX 高位拐头向下：趋势动能衰竭，容易进入震荡或者反转

### 五、ADXR 平均趋向评估指数

\(ADXR = \frac{ADX_{today}+ADX_{14天前}}{2}\)
用途：预判 ADX 拐点，提前预警趋势衰减；回测里用得偏少。

### 六、整套 DMI 实战规则

1. 先看 ADX：判断是不是趋势环境
   - ADX＜20：震荡，**放弃 DI 交叉信号**，改用震荡策略（布林下轨低吸这类）
   - ADX＞25：有效趋势，此时 DI 交叉可信度大幅提升
2. ADX>25 + +DI 上穿 - DI → 多头趋势入场信号
3. ADX>25 + -DI 上穿 + DI → 空头信号（用来做卖出、减仓信号）

## 七、DMI 优缺点（回测重点）

✅ 优点

1. 天然区分【方向】和【强度】，是行情自适应过滤利器，适配 “震荡 / 趋势两套规则” 的架构
2. Wilder平滑，相比普通均线，对跳空、单日大阳线不容易过度反应
3. 可以同时给个股、指数计算，大盘 DMI + 个股 DMI 双重过滤

❌ 缺点

1. 震荡市 DI 反复交叉，噪音巨大
2. 属于滞后指标，行情急速反转时信号滞后
3. 一字板、连续跳空会扭曲 TR、DM 计算，信号失真

### 八、指标体系搭配建议

- ADL / ADR：**大盘广度**，看市场整体赚钱效应（环境过滤）
- DMI(+DI,-DI,ADX)：**标的自身趋势状态**，区分震荡 / 趋势、多空方向
- BOLL+BBW：波动率通道，震荡做反转、收敛后做突破

> 
> 组合逻辑示例：
> 大盘 ADR、ADL 健康（多头广度）/ 个股 ADX>25（趋势行情）/ +DI > -DI（个股多头趋向），叠加基础策略买入条件 → 才允许买入
